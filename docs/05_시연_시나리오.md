## 추가 시연
- **제품에서 시작(기본 동선, 11/05)**: 브랜드 탭 에스트라 → "제품에서 시작" 카드 → 하이드로 수딩크림 **"이 제품으로 시안 만들기"** → 확인 시트(캠페인 이름=제품명, 핵심 메시지·타깃은 Haiku 제안, 지면은 이 브랜드의 마지막 캠페인 지면, 없으면 시연 기본 세트 6개. "바꾸기"로 플랫폼 > 광고 유형 > 지면에서 직접 고르거나 "시연 기본 6개") → **"바로 만들기"** → 캠페인 생성 + 카피 3안(1안 자동 선택) → 시안 탭 ④로 넘어가 모든 지면 이미지 생성이 저절로 돈다. 사용자가 한 일: 클릭 2, 입력 0. 1~4단계가 자동으로 채워진 뒤 5~7단계는 위 표와 같다. 목록에 없는 제품은 같은 카드 줄의 "제품 가져오기"
- **대조군 비교(S3)**: 타 브랜드 생성 입구에서 같은 브리프(상품명·설명·핵심 메시지 직접 입력)로 카피 생성 → 두 캠페인의 검수 결과를 나란히. 지식 있는 쪽의 '필수' 위반이 더 적고 근거가 붙는다.
- **지식 탭**: 에스트라 제품 층에서 하이드로 수딩크림 조각을 열어 "이 조각이 쓰인 카피"에 방금 만든 캠페인이 보인다.
