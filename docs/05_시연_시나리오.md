# 05. 시연 시나리오

> v2 · 2026-11-05. 00 정의서 v2(아모레퍼시픽 대표 브랜드 · 타 브랜드 대조군 · 7단계 안의 지식) 기준으로 다시 썼다. **시연 시나리오가 곧 개발 순서**이고,
> 이 시나리오를 처음부터 끝까지 돌려 막히는 곳이 다음 할 일이다(S1). v1(쿠챠 기준, 10/29 발표용)은 맨 아래에 남긴다.

## 시연 데이터
| 항목 | 값 |
|---|---|
| 입구 | **아모레퍼시픽 입장** (#/group) |
| 기준 브랜드 | 에스트라 (그룹 아모레퍼시픽, 지식: 규제 109 · 그룹 6 · 브랜드 1 · 제품 39) |
| 대조군 | **타 브랜드 생성** (#/studio) 에서 시연 직전에 직접 입력한 브랜드(지식 없음). 같은 브리프로 S3 비교 |
| 브리프 | 3단계 "제품 고르기"에서 **아토베리어365 하이드로 수딩크림** 선택 → 상품명·설명·제품 이미지 자동. 핵심 메시지: 속수분을 채우는 장벽 크림 · 타깃: 건조하고 민감한 30대 |
| 지면 6개 | Meta Instagram 피드 4:5 · Instagram 스토리 9:16 · Facebook 피드 4:5 · 카카오 디스플레이 네이티브 2:1 · 카카오 디스플레이 네이티브 1:1 · Google PMax 가로 1.91:1 |
| 일부러 위반하는 시안 | 핵심 메시지를 "아토피를 치료하는 장벽 크림"으로 바꿔 생성 → 금지 표현 '치료'(브랜드 규칙) + 의약품 오인(화장품법 제13조 제1항 1호 · 별표 5 가목)이 '수정 필요'로 막히고 근거 조문이 붙는 장면 |

## 7단계 (지식·검수가 보이는 자리와 함께)
| 단계 | 화면 | 보여 줄 것 | 확인 포인트 (성공 기준) |
|---|---|---|---|
| 1 브랜드 | 브랜드 탭 | 첫 화면 "아모레퍼시픽 입장" → 브랜드 탭이 열리고 그룹 줄에 설화수·라네즈·이니스프리·에스트라. 에스트라를 고르면 "등록된 지식: 규제 109 · 그룹 6 · 브랜드 4 · 제품 39 · 이 브랜드 자료 N" 한 줄 | 첫 화면이 브랜드 탭이다(S1). 지식 건수가 보인다 |
| 2 지면 | 규격·메시지·시안 탭 ① | 플랫폼 > 광고 유형 > 지면에서 6개 선택. 네이버는 '확인 필요 · 검수 불가' | 조건마다 강제/권장/미표기와 출처·확인일 |
| 3 메시지 | 규격·메시지·시안 탭 ② | **제품 고르기**에서 하이드로 수딩크림 → 상품명·설명·제품 이미지가 채워짐. 핵심 메시지·타깃만 입력. (목록에 없으면 "제품 가져오기") | 사용자 입력 2개(S1). 제품 이미지가 붙어 있다 |
| 4 생성 | 시안 화면 ③④ | 카피 3안 생성. **근거 패널**: 이번 카피가 본 규제(핵심 4건 항상 + 검색 보충)·브랜드·제품 조각과 각 시안의 angle·evidence → 배경 생성 → 로고·제목 합성 | 근거 없는 카피 0(S2). 핵심 규제가 항상 들어 있다(S4) |
| 5 편집 | 편집 패널 | 로고 잠금 확인 → 배경만 재생성 → 헤드라인 공통 수정 → 스토리만 지면별 수정 | 잠긴 로고 보존. 편집하면 검수 초기화 |
| 6 검수 | 검수 패널 | 통과/경고/수정 필요/확인 필요. 위반 시안에서 **'치료' → 금지 표현 + 의약품 오인, 근거 조문(제13조·별표 5 가목)과 수정 제안**이 붙는 장면. ("고쳐 보기"는 12 로드맵 §5, 아직 없음) | 위반마다 조문·제안(S2). 차단이 남으면 ZIP 비활성 |
| 7 다운로드 | 내보내기 | 검수 완료 ZIP → 지면별 폴더·copy.csv·검수결과.csv(근거 조문 열)·manifest.json | manifest 의 파일·sha256 일치 |

## 추가 시연
- **대조군 비교(S3)**: 타 브랜드 생성 입구에서 같은 브리프(상품명·설명·핵심 메시지 직접 입력)로 카피 생성 → 두 캠페인의 검수 결과를 나란히. 지식 있는 쪽의 '필수' 위반이 더 적고 근거가 붙는다.
- **지식 탭**: 에스트라 제품 층에서 하이드로 수딩크림 조각을 열어 "이 조각이 쓰인 카피"에 방금 만든 캠페인이 보인다.

| 날짜 | 어디까지 | 막힌 곳 | 조치 |
|---|---|---|---|
| 2026-11-05 | **7단계 완주**(캠페인 28, 에스트라 · 하이드로 수딩크림 · 지면 6). 1~3 은 화면에서, 4~7 은 API 로. 카피 3안(위반 0) → 지면 6개 이미지(4~23초) → 검수 119항목(통과 101 · 확인 필요 18) → 사람 확인 18건 → 검수 완료 ZIP 17파일(copy.csv·검수결과.csv·manifest.json) | ① 4단계 **근거 패널이 없다**(refs 는 브리프에 남지만 화면은 분석 탭의 건수뿐) ② 6단계 문구·법적 항목에 **조문·수정 제안이 없고** 검수결과.csv 에 근거 열이 없다 ③ 위반 시연이 성립하지 않는다: 핵심 규제가 프롬프트에 들어가니 모델이 '치료'를 피해 깨끗한 카피를 만든다(캠페인 30) ④ **대조군도 규제는 받는다**(캠페인 31: law 22, guide 0) — 규제는 업종 감지로 모든 브랜드에 들어가므로 "지식 없는 대조군"은 그룹·브랜드·제품 근거가 없는 것이지 규제까지 없는 것이 아니다 | ①② = S2 작업(다음). ③ 위반 장면은 5단계 공통 수정으로 '치료'를 넣은 뒤 6단계에서 잡히는 흐름으로 시나리오를 바꾼다. ④ **결정(11/05): 타 브랜드는 규제도 끈다.** 그룹 없는 브랜드는 `for_copy` 가 지식을 전혀 넣지 않는다(law_mode=off). 대조군 카피 재생성(캠페인 31): law 0 · guide 0 — 그래도 '치료'를 쓰지 않았다(카피 프롬프트의 공통 법적 안내 + 모델 성향). S3 비교는 위반 수보다 **근거 유무·제품 사실 정확성**이 먼저 드러난다 |
