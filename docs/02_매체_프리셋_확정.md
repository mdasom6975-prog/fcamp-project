## 매체별 규격

### Meta (공식: facebook.com/business/ads-guide)
공통: JPG·PNG, 최대 30MB(기술 요구 사항)

| 지면 | 비율 / 권장 해상도 | 최소 크기·허용 오차 | 문구 | 안전영역 |
|---|---|---|---|---|
| Instagram 피드 | 4:5 / 1440×1800 | 너비 500px, 최소 비율 "400x500", 최대 "191x100"(표기 모호), 허용 1% | 기본 125자, 제목 40자, 해시태그 30개 | 확인 불가 |
| Instagram 스토리 | 9:16 / 1440×2560 | 너비 500px, 허용 1% | 기본 125자(권장) | 상 14%, 하 35%, 좌우 6% |
| Facebook 피드 | 4:5 / 1440×1800 | 너비 600px, 높이 750px, 허용 3% | 기본 50~150자, 제목 27자 | 확인 불가 |
| Instagram 릴스 | 9:16 / 1440×2560 | 너비 500px, 높이 확인 불가, 허용 1% | 기본 44자(권장) | 상 14%, 하 35%, 좌우 6% |

- 충돌: Facebook 피드 비율을 본문은 4:5 하나만, 검색 요약은 1.91:1~4:5 범위로 표기 → 본문 기준, 범위 미확정
- 필수 자산(로고 등): 해당 페이지에 요건 없음. 설명·CTA 글자 수와 계수 방식(공백 포함 여부) 확인 불가.

### Google Ads (공식: support.google.com/google-ads)
| 자산 | 비율 / 권장 | 최소 | 용량 | 필수 |
|---|---|---|---|---|
| RDA 가로 | 1.91:1 / 1200×628 | 600×314 | 5,120KB | 필수 |
| RDA 정사각형 | 1:1 / **600×600 또는 1200×1200(충돌)** | 300×300 | 5,120KB | 필수 |
| RDA 로고 1:1 | 1:1 / 1200×1200 | 128×128 | 5,120KB | 선택(RDA) |
| RDA 로고 4:1 | 4:1 / 1200×300 | 512×128 | 5,120KB | 선택 |

문구(RDA): 제목 30자(1~5개), 긴 제목 90자(1), 설명 90자(1~5), 업체 이름 25자(1) — 모두 필수.
- 파일 형식(.jpg/.png)은 PMax 문서에서만 확인, RDA 문서에서는 확인 불가
- 한글 전각 문자 계수(글자당 2자)는 PMax 문서에서만 명시, RDA 적용 여부 확인 불가
- 안전영역: 확인 불가

### 카카오 (공식: kakaobusiness.gitbook.io, developers.kakao.com)
| 지면 | 크기 | 형식·용량 | 문구 |
|---|---|---|---|
| 디스플레이 네이티브 2:1 | 최소 1200×600 | JPG/JPEG/PNG, 500KB | 타이틀 25자, 홍보문구 45자, 프로필명 20자 |
| 디스플레이 네이티브 1:1 | 최소 500×500 | JPG/JPEG/PNG, 500KB | 동일 |
| 비즈보드 배너 | 1029×258 | PNG-24/32, 300KB, 투명 배경 | **px 길이 기준**: 텍스트 중 하나 최소 290px |
| 채널 메시지 와이드이미지형 | 800×600(4:3) | JPG/JPEG/PNG, 10MB | 내용 76자(줄바꿈 5회), 버튼 8자 |

- 디스플레이 2:1 세이프존(권장): 상단·좌우 40px, 하단 90px 안에 텍스트·로고·주요 오브젝트 배치 지양
- 디스플레이 공통 필수: 프로필 이미지 300×300 이상 1:1, 500KB, 행동유도문구
- 디스플레이 이미지 내 텍스트 권장: 48~164px, 2:1은 최대 3줄, 폰트 스타일·컬러 4가지 이상 불가(필수)
- 비즈보드: 광고주체 표기 필수, 우측 상단 66×174px AD 마크 영역 겹침 불가
- 채널 메시지: 이미지 규격은 "권장"이고 필수 여부 원문 미표기
- 충돌: 세이프존 수치가 검색 요약과 원문 표에서 다름 → 원문 표 기준, 재대조 필요

### 네이버
- 공식 도메인(ads.naver.com 등) 접근 불가로 규격 **확인 불가**
- 화면에는 "확인 필요"로 표시하고 **검수 대상에서 제외(검수 불가)**. 비공식 수치는 사용하지 않음.

## 확정된 결정 (2단계)
1. **Google RDA 정사각형**: 권장 크기 600×600과 1200×1200을 둘 다 저장하고 "충돌"로 표시한다. 강제 조건은 공식 최소 300×300만 적용한다.
2. **제작 기본값 규칙**: 공식 권장 해상도를 쓰고, 공식 권장값이 없으면 공식 최소치를 쓴다.

## 사용자 결정이 필요한 남은 항목
1. Facebook 피드 비율 범위: 본문 기준 4:5만 허용할지
2. 네이버 확인 필요 프리셋의 노출 방식
3. 필수 여부 미표기 항목(카카오 채널 메시지 등)의 검수 처리
4. 아이콘 등 비광고 자산의 용도 규격("웹용/사용자 지정") 기본값

## 데이터 구조(01) 반영 사항 (반영 완료)
- text_limits.count_method: 글자 수 / px 길이 / 전각 2자 계산
- PresetVersion.status: 확인됨 / 충돌 / 확인 필요(검수 불가)
- PresetVersion.production_default: 제작 기본값 (미확정 허용)

## 구현 현황 (5단계)
- 규격 라이브러리 화면: 매체 > 광고 유형 > 지면 선택, 다중 선택, 규격 상세(조건·문구 제한·안전영역·출처·확인일·상태)
- 네이버: 매체 단위로만 표시("확인 필요 · 검수 불가"), 선택 가능한 지면 없음
- 규격 추가·수정·비활성화 UI는 프로젝트 2 범위로 제외
- 선택한 규격의 저장은 시안 생성 단계(Design.preset_version_ids)에서 연결

## 변경 이력 — 지원 지면 제외 (사용자 결정)
- 제외: Meta · Instagram 릴스, Google Ads · RDA 4종(가로 1.91:1, 정사각형 1:1, 로고 1:1, 로고 4:1)
- 방식: 시드에서 제거하고, 기존 DB 에 남아 있으면 기동 시 비활성화(삭제하지 않음). 활성 규격이 없는 매체는 목록에서 숨김
- 제외된 지면으로는 시안을 만들 수 없음(400). 이미 만든 시안의 이력은 보존
- 현재 지원: Meta 3개(Instagram 피드, Instagram 스토리, Facebook 피드), 카카오 4개(디스플레이 네이티브 2:1·1:1, 비즈보드 배너, 채널 메시지 와이드이미지형), 네이버(확인 필요·검수 불가)
- **RFP 요건 점검**: '3개 이상 매체'는 현재 사용 가능한 매체가 Meta·카카오 2개이고 네이버는 규격 미확인이라 충족하지 못함. '6개 이상 프리셋'은 7개로 충족. 매체 추가 또는 네이버 규격 확인 필요
- 참고: Google Ads 의 다른 이미지 광고 유형(업로드형 디스플레이, 성과 최대화)은 공식 문서에서 확인한 값이 있으나 시드에 넣지 않았음

- PMax 문구 수량(광고 제목 3개 이상, 설명 2개 이상)은 사용자 결정으로 '수정 필요(차단)'. 현재 1세트만 생성하므로 PMax 는 '검수 완료' 내보내기가 불가능하고 미검수 작업본으로만 내보낼 수 있음

- 업로드형 크기는 문서의 지원 크기 목록 중 선택한 3종만 지원
