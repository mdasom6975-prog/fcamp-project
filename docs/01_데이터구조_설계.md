# 01. 데이터 구조 설계 (프로젝트 1 필수 5개 범위)

> 근거: RFP "브랜드 아이콘·마케팅 콘텐츠 생성 및 Meta 광고 운영 플랫폼 개발" (콘텐츠 도메인)
> 원칙: RFP에 없는 기능은 만들지 않는다. 결정이 필요한 항목은 사용자와 확인 후 확정한다.

## 엔티티
### Brand / BrandVersion
- Brand: id, name, current_version_id
- BrandVersion: brand_id, version_no, created_at, 아래 규칙 묶음 (변경 시 새 버전, 기존 버전 보존)
  - logo: asset_id, 원본 비율(보존), 여백
  - colors[]: name, hex, role
  - fonts[]: family, role
  - icon_style: 선 굵기, 모서리
  - image_tone, voice(어조)
  - required_phrases[], forbidden_phrases[]
  - 모든 규칙에 level: 필수 / 권장 / 수정가능

### Asset
- id, brand_id, kind(logo | product | background | icon | generated), file_path, mime, bytes, width, height

### 규격 라이브러리 (Platform → Placement → PresetVersion)
- Platform: name
- Placement: platform_id, 광고 유형, 지면, content_kind(완성형 | 분리 자산형), 용도(광고 | 웹용 | 사용자 지정)
- PresetVersion: placement_id, version_no, active
  - width, height, allowed_ratios, min_resolution, formats[], min_bytes, max_bytes
  - text_limits[]: field(제목·본문·CTA 등), max_chars 또는 max_px, count_method(글자 수 | px 길이 | 전각 2자 계산)
  - safe_area, required_assets[]
  - 조건마다 level: 강제 / 권장 / 제작 기본값
  - production_default(제작 기본값, 미확정 허용), source_url, checked_at, status(확인됨 | 충돌 | 확인 필요=검수 불가), 충돌 시 값 목록 보존  ← 수치는 AI 추측 금지, 공식 문서 확인 후에만 '확인됨'

### Design (시안)
- brand_id, brand_version_id, preset_version_ids[], brief(상품·메시지), kind(아이콘 세트 | 광고 이미지), status(미검수 | 검수 완료 | 수정됨)
- DesignSnapshot: design_id, saved_at, elements 전체 (저장 시점 보관, 복원/비교 UI 없음)

### Element (편집 요소, 지면별)
- design_id, preset_version_id, type(text | logo | image | shape), x, y, w, h, color, font, z_index, locked
- scope: 공통 / 지면별 값 구분 (공통 수정 전체 적용 vs 개별 수정)

### ReviewResult
- design_id, preset_version_id, item, status(통과 | 경고 | 수정 필요 | 확인 필요), message, location
- 시안 수정 시 기존 결과 무효화 → 재검증

### Export
- design_id, brand_version_id, preset_version_ids[], files[](파일명·형식·용량), review_summary, zip_path, created_at
- 규격상 필수 위반 또는 필수 기준 미확인이면 '검수 완료' 묶음 내보내기 차단

## 구현 현황 (6-1 시안 만들기)
- Design: brand_id, brand_version_id(저장 시점의 현재 버전), kind(광고 이미지 | 아이콘 세트), preset_version_ids, brief
- brief: 상품/서비스명(필수), 상품 설명, 핵심 메시지, 타깃 고객 (+ 아이콘 세트는 icon{용도, 크기})
- brief.required_phrases / forbidden_phrases (10/19 추가): 캠페인 필수·금지 표현. **캠페인 입력이 우선**이고 비어 있으면 브랜드 규칙(BrandVersion) 값을 쓴다 — 필수·금지 각각 따로 판단(`phrases.effective`). 카피 생성·검수·내보내기·편집 경고·아이콘 기능명 검사가 모두 이 규칙을 거치고, 응답의 `effective_phrases` 에 적용 값과 출처(캠페인|브랜드)를 돌려준다. 같은 문구가 양쪽에 있으면 422. 브랜드 쪽 입력 화면은 그대로 두고 ② 상품·메시지 입력에 같은 입력 상자를 추가
- 광고 이미지: 규격 1개 이상 필수, '확인 필요' 규격(네이버)은 선택 불가
- 아이콘 세트: 규격 대신 용도(웹용 | 사용자 지정). 사용자 지정은 크기 필수, **웹용 기본 크기는 6-4에서 확정**
- 브랜드가 새 버전으로 바뀌면 시안 목록에 "브랜드가 버전 N으로 변경됨" 표시

## 구현 현황 (6-2 카피 생성)
- CopyVariant(신규 테이블): design_id, preset_version_id, batch_no, variant_no, headline/body/cta, limits, violations, attempts
- **캠페인당 1회 생성, 모든 지면이 같은 문장 3세트** (10/19 변경, 이전: 지면마다 따로 생성 → 시안 A 가 매체마다 다른 문장). 선택 지면의 글자 수 제한을 가장 엄격한 값으로 합쳐(`copywriter.merge_limits`: max 는 최소, min 은 최대, 전각 2자 계산은 한글 기준 M//2 환산) 생성 조건으로 주고, 행은 지면마다 저장하되 위반은 각 지면 제한으로 다시 검사. 생성 호출은 지면 수와 무관하게 1회
- 시안 선택: `POST /designs/{id}/copy/select-variant {variant_no}` 가 모든 지면의 같은 번호를 한 번에 고른다(매체 간 카피 통일). 화면의 '이 시안 선택'·카피 후보 라디오 모두 이 경로
- 위반(글자 수 초과/미달, 금지 표현 포함, 필수 표현 누락, 빈 값)이 있으면 1회 자동 재생성, 위반이 적은 결과를 채택하고 남은 위반은 화면에 표시
- 제한 필드 연결: 제목={제목, 광고 제목, 타이틀} / 본문={기본 문구, 설명, 홍보문구, 내용} / CTA={버튼명}
- 이번 단계 제외: 긴 광고 제목·업체 이름·프로필 이름·해시태그(생성 대상 아님), 비즈보드 배너 카피(px 길이 → 검수 단계에서 폰트로 측정)
- 모델: 환경변수 CHAT_MODEL (기본 gpt-5.4-mini)

## 구현 현황 (6-3 이미지 생성 + 합성)
- GeneratedImage(신규): kind(background | composite), file_path, 크기, prompt, copy_variant_id, brand_version_id, layout(요소 위치·글자 크기·색·경고)
- CopyVariant.selected: 지면당 합성에 쓸 카피 1개
- 배경은 **비율군(템플릿)마다 1장** 생성한다 (10/19 변경, 이전: 정사각 1장을 모든 지면이 공유 → 9:16·2:1 에서 피사체 잘림·여백 과다). 세로형 1024×1536 / 가로형 1536×1024 / 정사각 1024×1024 (gpt-image 지원 크기, `imagegen.size_for`). 같은 비율군 지면은 같은 파일을 공유하고, 비용은 시안에 있는 비율군 수(1~3장, 비정사각은 토큰 약 1.5배)만큼 든다. `IMAGE_BG_PER_RATIO=0` 이면 이전 방식. 배경 행 layout 에 {template, size, style, style_reason, prompts(프롬프트 ref)} 기록
- 매체 간 장면 통일(10/19 추가 요청): 비율군이 여럿이면 **첫 비율군(시안의 첫 규격) 배경만 프롬프트로 생성**하고, 나머지 비율군은 그 이미지를 참조로 붙여 `images.edit`(input_fidelity high) 로 같은 장면·소품·색을 유지한 채 해당 비율의 구도로 다시 만든다(`imagegen.generate_variant`, 문장은 `prompts/image/same_scene.md`). 규격 하나만 다시 만들 때도 시안의 최신 배경을 참조한다. 변형 행 layout.reference 에 참조 배경 id·파일·템플릿 기록. 비용·한도는 생성 1장과 같고, `IMAGE_BG_VARIANT=0` 이면 비율군마다 독립 생성(이전: Meta/카카오/Google 배경이 전부 다른 장면이던 문제)
- '이미지 생성' 흐름(make_image 연쇄, 10/19 수정): 같은 비율군 배경이 있으면 연결, 없고 다른 비율군 배경만 있으면 그 장면을 참조한 변형 1장을 만들어(비율군마다 1장 원칙) 자른다. 변형이 안 되면(공급자 거절·FLUX) 예전처럼 다른 비율군 배경을 잘라 쓰고 layout.fallback 기록. 이전에는 이 흐름이 항상 첫 배경만 잘라 써서 '배경 새로 생성'을 눌러야만 비율군별 배경이 생겼다
- 모델 호환(10/19): gpt-image-2.5 계열은 `input_fidelity` 를 거절한다 → 거절되면 그 인자만 빼고 한 번 더 보내고 이후 호출부터 보내지 않는다(`imagegen._fidelity_supported`). OpenAI SDK 는 오류 응답의 error 안쪽 dict 를 `e.body` 로 주므로(래퍼 없음) `imagegen.error_info` 가 양쪽 모양을 읽는다 — 처음 구현은 래퍼만 봐서 재시도가 되지 않고 폴백으로 빠졌었다. 변형 생성이 그래도 실패하면 첫 배경(이미 과금됨)을 버리지 않고 그 비율군은 첫 배경을 잘라 쓰며 layout.fallback 과 응답 warnings 에 사유를 남긴다. 생성 실패 502 메시지에는 공급자 오류 문구를 붙이고 서버 로그에 traceback 을 남긴다
- 지면 크기 맞춤은 늘이지 않고 자르되 **내용 상자 기준**(`compose.content_box` → `crop_window`): 경계선(질감)이 많은 행·열로 피사체 상자를 찾아 창에 담고, 못 담으면 윗변에 맞춘다(얼굴은 피사체 위쪽). 초점(zoom, cx, cy)은 layout.crop 에 남겨 편집 화면 초기값으로 쓴다. 위/아래가 잘리면 경고
- 여백 축소(10/19 사용자 요청): (1) 프롬프트 — composition 1.3(세로형 65/35, 정사각 70/30, 가로형 피사체 높이 70%↑), background 1.3·style 1.1 에서 '피사체를 작게/멀리서' 지시를 '크게 채우기'로 바꿈. (2) 크롭 — 피사체가 작으면 최대 1.3배 확대해(`MAX_TIGHTEN`) 피사체가 세로형·정사각은 높이의 55~60%, 가로형은 폭의 60% 를 차지하게 하고 문구 자리(아래/왼쪽)는 남긴다. (3) 합성 — 제목 시작 크기 7.5%→9%, 문구는 내용 상자(피사체)를 덮지 않게 그 아래/왼쪽으로만(자리가 없으면 경고), 세로형·정사각에서 위 모서리가 비어 있으면 로고를 위로 올려 아래 띠를 문구에 양보. 피부색 판정이 노란 벽을 사람으로 오인하던 버그 수정
- 배경 형태(`brief.image_style`, 기본 "자동"): 실사 인물 / 실사 제품·공간 / 플랫 일러스트 / 3D 렌더 / 그래픽 패턴. 자동이면 브랜드 image_tone·브리프 설명의 키워드(일러스트→플랫, 3D·렌더·레진→3D, 패턴·그래픽→패턴, 인물·사람→실사 인물)로 고르고 단서가 없으면 **사람 없는 실사 제품·공간**(`imagegen.pick_style`). 문장은 `prompts/image/style/*.md` 에만 있고 `background.md` 1.2 가 `{{style}}` 로 넣는다. 입력 화면 ② 와 이미지 패널의 "배경 새로 생성"(body `style`) 에서 고른다
- 완성형: 배경 + 로고(원본 비율) + 제목을 코드로 합성. 이미지에는 제목만 넣고 본문·CTA 는 별도 문구로 둠
- 분리 자산형(Google RDA, 카카오 비즈보드): 텍스트 없는 이미지만 생성. 로고·카피는 내보내기에서 별도 파일
- 템플릿: 가로형(비율 1.25 이상) / 정사각 / 세로형(0.8 이하). 지면 안전영역이 있으면 반영, 없으면 짧은 변의 6% 여백
- 로고 자리: 기본은 **브랜드 설정의 고정 자리**(좌상단 기본·우상단·좌하단·우하단) — 캠페인의 모든 지면이 같은 모서리를 써서 브랜드 인지가 흔들리지 않는다. 복잡도 0.5 이상이면 반투명 판. 브랜드가 '자동'을 고르면 후보(가로형 좌상·우상·우하, 세로형·정사각 좌상·우상·**좌하·우하**) 중 이미지가 가장 단순한 곳(`pick_logo_corner`). 아래 모서리가 뽑히면 제목을 로고 위에 쌓는다 — 피사체가 위쪽에 오는 구도에서 로고가 얼굴을 가리던 문제(캠페인 2 Instagram 피드) 해결
- 제목 가독성: 문구 블록을 6×3 칸으로 나눠 가장 약한 칸의 대비가 4.5:1 미만이거나 배경이 복잡하면 블록 뒤에 흐린 판(`text_backing`, 스크림색 50%)을 한 장 더 깔고, 제목·본문은 항상 부드러운 그림자(`draw_text_soft`)와 함께 그린다. 편집 렌더도 같은 스타일.
- 문구 색: 브랜드 텍스트색을 쓰되 배경 대비 4.5:1 미만이면 흰색/검정으로 대체하고 경고 표시
- 같은 배경으로 재합성은 비용 없이 가능, 배경 새로 생성은 별도 버튼
- 시안 이미지 초기화(`POST /reset-generated`): 배경·합성·편집 요소·검수 결과 삭제, include_copy 로 카피, **include_icons 로 아이콘 세트**(브랜드 규칙 버전 소유라 같은 버전의 다른 캠페인에서도 사라짐, 파일 포함)까지. 축소본 캐시도 정리
- 로고 SVG 는 resvg-py 로 렌더링

## 구현 현황 (6-6 브랜드·규격 검수)
- ReviewResult: category(규격|문구|브랜드|시안), item, status(통과|경고|수정 필요|확인 필요), level, message, blocking, needs_human, confirmed, valid

- 공식 기준이 확인되지 않았거나 충돌인 '강제' 조건 → 확인 필요 + 차단 (RFP: 필수 기준 미확인 시 차단)
- 자동 판정이 어려운 항목(px 길이 문구, 이미지 톤·어조, 광고주체 표기, AD 마크 영역, 프로필 이미지 등) → 확인 필요 + 사람이 '확인함' 표시. 브랜드 구분이 '필수'인 톤·어조만 확인 전까지 차단
- 파일 검사: 최신 합성본을 허용 형식 순서(PNG 우선, 한도 초과 시 JPG 품질을 낮춰)로 실제 인코딩해 형식·용량 판정 (exporting.encode, 내보내기에서 재사용)
- 필수 문구 중 아직 생성하지 않는 항목(RDA 긴 광고 제목·업체 이름, 카카오 프로필 이름)은 수정 필요 + 차단
- Meta '최소/최대 화면 비율'(10/19): 공식 페이지가 비율을 픽셀 쌍(400x500 / 191x100)으로 적는 것이라 '모호'가 아니라 4:5~1.91:1 범위다. 시드를 확인됨으로 바꾸고 review 가 W/H 가 범위 안인지('비율 허용 오차' 적용) 자동 판정한다('화면 비율 범위'). 시드의 조건·상태가 바뀌면 기동 시 `seed.sync_conditions` 가 기존 지면에도 반영
- 시안·카피·이미지·아이콘이 바뀌면 해당 지면의 검수 결과를 무효화(valid=false). 다른 지면 결과는 유지
- 검수 결과가 전부 차단 없음이면 시안 상태 '검수 완료'
- 아이콘 세트: 기능 수(10개 이상), 여백, 금지 표현. 스타일·색은 방식별 — svg: 선 굵기·모서리·채움·색 코드 판정 / 3d: 세트 전체가 같은 스타일 블록·모델·품질인지 코드 판정, 색은 '확인 필요'(사람), 투명 배경 아니면 '수정 필요'
- 아이콘 항목의 위치(10/19 수정): 캠페인의 브랜드 규칙 버전에 아이콘 세트가 있으면 광고 이미지 캠페인의 검수 결과에 **지면 없는 그룹 '아이콘 세트'(preset_version_id=None)** 로 함께 들어간다. 세트가 없는 캠페인에는 그룹이 생기지 않는다. 세트가 10개 미만이면 '기능 수' 가 차단이라 캠페인 전체의 '검수 완료' 내보내기가 막힌다(미검수 작업본은 가능). 프론트 ReviewPanel 은 이 그룹을 지면 선택과 무관하게 항상 포함해 보여 준다

## 구현 현황 (6-7 규격별 파일 내보내기)

- '미검수 작업본': 차단 항목이 있어도 생성 가능. 파일명·manifest 에 상태를 표시하고 미해결 항목을 '미검수_작업본.txt' 로 동봉

- 이미지는 매체 허용 형식으로 인코딩(PNG 우선, 용량 초과 시 JPG 품질을 낮춤). 아이콘은 icons/png(출력 크기) + 3d 는 icons/src(1024 투명 원본), svg 방식은 icons/svg
- 아이콘 세트의 포함 규칙(10/19 수정): 캠페인의 브랜드 규칙 버전에 세트가 있으면 지면 선택과 무관하게 **항상** ZIP 에 들어가고, manifest.presets 에 `{name: "아이콘 세트", count, size, render, style, prompts, review, ready}` 한 줄을 남긴다. 지면도 세트도 없으면 409. '검수 완료' 판정은 선택한 지면 + 아이콘 세트 그룹이 모두 차단 없음일 때
- 편집·카피 변경 후에는 검수 결과가 무효화되어 '검수 완료' 내보내기가 거절됨(재검수 필요)
