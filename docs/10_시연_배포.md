# 10. 시연 배포 (클라우드 VM 1대 + cloudflared)

> Vercel + Supabase 로 올리는 방식은 `11_Vercel_Supabase_배포.md`. 이 문서의 VM 방식은 SQLite·로컬 파일을 그대로 쓰는 대안이다.

개인 학습·단기 시연용 배포 절차. 서버 DB·Docker·도메인 없이, 작은 Ubuntu VM 한 대에 앱을 올리고 cloudflared 빠른 터널로 HTTPS 주소를 받는다.
운영 파일은 `deploy/` 에 있다: `install.sh`(1회 준비), `brand-studio.service`(백엔드), `cloudflared.service`(터널), `backup.sh`(백업).

## 1. 구성

```
[브라우저] --https--> trycloudflare.com --터널--> [VM] cloudflared --> uvicorn :8000 (127.0.0.1)
                                                                    ├─ /api/*   FastAPI + SQLite(backend/data/app.db) + backend/storage
                                                                    └─ /        frontend/dist (Mac 에서 빌드해 scp)
```

- 접근 제한: `.env` 의 `APP_PASSWORD` 가 비어 있지 않으면 모든 요청에 HTTP Basic 인증(사용자명 `APP_USER`, 기본 `demo`)을 요구한다. `/api/health` 만 예외. 브라우저에서는 로그인 창이 뜬다.
- `APP_PUBLIC=1` 이면 `/docs`·`/redoc`·`/openapi.json` 을 끈다.
- `frontend/dist/index.html` 이 있으면 백엔드가 루트에서 프론트를 함께 서빙한다(없으면 API 만). VM 에 Node 는 필요 없다.
- 터널 주소는 cloudflared 를 재시작할 때마다 바뀐다. 시연 직전에 확인해서 공유한다.

## 2. VM 선택

| 선택지 | 사양 | 월 비용 | 비고 |
|---|---|---|---|
| Oracle Cloud Always Free (ARM, A1.Flex) | 최대 4 OCPU / 24GB, 보통 1~2 OCPU·6GB 로 생성 | 0원 | 가입 시 카드 필요, 리전에 따라 "Out of capacity" 로 생성이 안 될 때가 있어 시간을 두고 재시도. ARM64 이므로 `install.sh` 가 arm64 cloudflared 를 받는다 |
| GCP e2-micro (us-west1/us-central1/us-east1) | 공유 vCPU 0.25 / RAM 1GB | 0원(무료 티어) | RAM 이 작아 스왑 2GB 가 필수. 이미지 합성·pip 설치가 느리다 |
| 소형 유료 VM (Vultr·Hetzner·Lightsail 등 1 vCPU / 1~2GB) | 1 vCPU / 1~2GB | 약 5,000~9,000원 | 생성이 확실하고 빠르다. 시연 뒤 바로 삭제하면 시간 단위로 과금 |

권장: Oracle ARM 이 만들어지면 그것을, 안 되면 소형 유료 VM. Ubuntu 24.04(Python 3.12) 이미지로 만든다.
방화벽은 SSH(22) 만 열면 된다. 8000 번은 열지 않는다(cloudflared 가 VM 안에서 내보낸다).

## 3. 절차

1. **인스턴스 생성**: Ubuntu 24.04, SSH 키 등록. (Oracle: VCN 기본값, Public IP 할당.)
2. **ssh 접속**
   ```bash
   ssh ubuntu@<공인 IP>
   ```
3. **저장소 clone** (비공개 저장소면 VM 에서 `gh auth login` 하거나 HTTPS 토큰 사용)
   ```bash
   git clone <저장소 URL> ~/project && cd ~/project
   ```
4. **1회 준비**: apt → venv → pip → 폴더 → 스왑 2GB → cloudflared
   ```bash
   bash deploy/install.sh
   ```
5. **`backend/.env` 작성** (Mac 의 `.env` 에서 키 4개를 옮기고 시연 권장값을 더한다)
   ```bash
   # API 키 4개
   OPENAI_API_KEY=...
   ANTHROPIC_API_KEY=...
   CLOUDFLARE_ACCOUNT_ID=...
   CLOUDFLARE_API_TOKEN=...
   # 시연 권장값
   IMAGE_DAILY_LIMIT=30            # 하루 이미지 생성 상한(장). 실수·남용으로 과금이 커지지 않게
   APP_PASSWORD=<시연용 비밀번호>   # 비우면 누구나 접속 가능
   APP_USER=demo                   # 생략 가능(기본 demo)
   APP_PUBLIC=1                    # API 문서 숨김
   ```
6. **프론트 빌드 → 업로드** (Mac 에서)
   ```bash
   cd frontend && npm run build && scp -r dist ubuntu@<공인 IP>:~/project/frontend/
   ```
7. **서비스 등록** (VM 에서. 저장소가 `/home/ubuntu/project` 가 아니면 두 service 파일의 경로를 먼저 고친다)
   ```bash
   sudo cp deploy/brand-studio.service deploy/cloudflared.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now brand-studio cloudflared
   curl -s http://127.0.0.1:8000/api/health     # {"status":"ok","presets":N}
   ```
8. **터널 주소 확인**
   ```bash
   journalctl -u cloudflared --no-pager | grep -o 'https://[a-z0-9-]*\.trycloudflare\.com' | tail -1
   ```
   브라우저에서 그 주소를 열면 Basic 로그인 창 → `demo` / `APP_PASSWORD`. 주소는 cloudflared 재시작마다 바뀐다.
9. **브랜드 넣기** (VM 에서. 비밀번호를 켰으면 주소에 자격을 넣는다. 더미 캠페인은 없고 `brands/kucha` 만 등록된다. 캠페인은 화면에서 직접 입력)
   ```bash
   backend/.venv/bin/python tools/seed_demo.py --base http://127.0.0.1:8000           # 비밀번호 없을 때
   backend/.venv/bin/python tools/seed_demo.py --base http://demo:<비밀번호>@127.0.0.1:8000
   ```
10. **시연 뒤 정리**
    ```bash
    bash deploy/backup.sh && scp -r ubuntu@<공인 IP>:~/backups ./   # 남길 데이터가 있으면
    ```
    콘솔에서 인스턴스를 **삭제**(중지만 하면 디스크 요금이 남는 곳이 있다)하고, `.env` 에 넣었던 **API 키 4개를 재발급**한다. VM 에 올라간 키는 노출된 것으로 본다.

문제 확인: `journalctl -u brand-studio -f`(앱 로그), `journalctl -u cloudflared -f`(터널), `sudo systemctl restart brand-studio`(코드·`.env` 바꾼 뒤).
코드 갱신: `git pull && sudo systemctl restart brand-studio`, 프론트는 6번을 다시 한다. 터널 주소는 cloudflared 를 건드리지 않으면 유지된다.

## 4. 비용 요약

| 항목 | 금액 | 근거 |
|---|---|---|
| 서버 | 0~9,000원/월 | Oracle/GCP 무료 티어 0원, 소형 유료 VM 5,000~9,000원. 시연 뒤 삭제하면 일할 |
| 캠페인 1개 생성 | 약 200~400원 | 카피 1회(Claude) + 확정 배경 1~3장(gpt-image, medium) + 아이콘 10장. 시안 배경을 Cloudflare 로 돌리면 아래쪽 |
| 분석 탭 비전 채점 | 건당 수십 원 | 누를 때만 과금 |
| 상한 | `IMAGE_DAILY_LIMIT=30` + 콘솔 월 예산 | OpenAI·Anthropic 콘솔에서 월 사용 한도(예: $10)를 걸어 둔다. Cloudflare Workers AI 는 무료 할당량 안에서 쓴다 |

## 5. 고정 주소가 필요해지면

Cloudflare 계정에 도메인을 붙이고 이름 있는 터널을 만든다(`cloudflared tunnel login` → `create` → `route dns`). `deploy/cloudflared.service` 의 ExecStart 를 `cloudflared tunnel run <이름>` 으로 바꾸면 나머지는 같다.
