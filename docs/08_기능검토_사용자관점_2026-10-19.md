## 2. 브랜드 화면

| 우선 | 문제 | 보완 제안 |
|---|---|---|
| 중간 | 필수 표현을 "로켓, 배송, 프레시, 직구"처럼 4개 넣으면 매체 공통 카피(제목 15자·본문 45자)에 전부 넣기 어려워 시안 B·C가 거의 항상 '필수 표현 누락'이 된다. 화면에 이런 영향이 안내되지 않는다 | 필수 표현 3개 초과 시 경고("카피가 짧은 지면에서는 모두 넣기 어렵습니다"). "로켓배송"처럼 한 단어로 묶기 안내 |
| 중간 | "시안 만들러 가기"가 저장 직후에만 보인다. 기존 브랜드를 열어 보기만 하면 캠페인으로 가는 길이 없다 | 브랜드를 열면 항상 "이 브랜드로 캠페인 만들기" 노출 |

| 낮음 | 이전 버전을 고르면 폼이 그 버전으로 바뀌지만 "이전 버전을 보는 중"이라는 표시가 작다 | 버전 셀렉트 옆에 "v1 보는 중 · 현재는 v2" 배지 |

## 3. 캠페인 — 입력(②)과 카피(③)

| 우선 | 문제 | 보완 제안 |
|---|---|---|
| 높음 | 시안 카드의 위반 목록이 지면마다 한 줄씩 반복돼(“✕ 디스플레이 네이티브 2:1 본문(홍보문구): 57자 / 최대 45자” ×6) 카드가 길고 어떤 시안을 고를지 판단이 어렵다 | 카드에는 "글자 수 초과 2개 지면 · 필수 표현 누락 2개"로 요약하고, 자세한 줄은 펼치기. 지면별 통과/실패를 작은 점으로 |
| 높음 | 카피 모델이 합친 제한(제목 15자·본문 45자)을 넘기는 결과가 자주 나온다(이번 실행: A 제목 31/30 전각, B·C 본문 54~57/45) | 재시도 1회 외에, 넘친 문장을 제한 안으로 **자동 축약**하는 2차 호출 또는 카드에서 바로 고치는 인라인 편집 |
| 중간 | 카드에는 본문·CTA까지 보이지만 이미지에는 제목만 들어가고 본문·CTA는 내보내기 copy.txt로만 간다. 화면 어디에도 이 사실이 없다 | 카드에 "이미지에는 제목만 · 본문/CTA는 광고 플랫폼 입력용" 표시 |
| 중간 | "공통 문구 수정" 상자가 카피와 이미지 사이에 있고, 카피가 매체 공통이 된 지금은 역할이 헷갈린다(합성 뒤에만 동작) | 편집 화면으로 옮기고 "모든 지면 제목 일괄 수정"으로 이름 변경 |
| 중간 | 카피 다시 생성을 누르면 이전 선택이 풀리는데 안내가 없다. 선택 없이 이미지 생성 버튼이 비활성인 이유를 알기 어렵다 | 다시 생성 후 "시안을 다시 골라 주세요" 안내, 비활성 버튼에 이유 툴팁 |
| 낮음 | ② 입력의 "배경 형태"와 ④ 이미지 패널의 "배경 형태" 셀렉트가 두 군데다 | 한 곳(④)만 두고 ②에는 요약만 |

## 4. 캠페인 — 이미지 생성(④)

| 우선 | 문제 | 보완 제안 |
|---|---|---|
| 높음 | 지면이 탭 하나씩만 보여 6개 매체를 한눈에 비교할 수 없다(배경 통일 여부도 탭을 돌려야 안다) | 탭 대신 **썸네일 그리드**(6개 합성본 + 지면명 + 경고 수)와 클릭 시 확대. 편집·검수 화면도 같은 그리드 |
| 높음 | "시안 이미지 초기화"(생성 결과 전부 삭제)가 "배경 새로 생성" 바로 옆에 같은 모양으로 있다 | 위험 동작은 메뉴(…) 안으로, 빨간색·확인 대화상자 유지 |
| 중간 | 첫 "이미지 생성" 버튼이 현재 탭 지면에만 있어, 6개를 만들려면 탭마다 눌러야 하는 것처럼 보인다(실제로는 나머지도 이어서 합성됨) | "모든 지면 이미지 생성" 버튼 하나로 바꾸고, 지면별 버튼은 "이 지면만 다시" |
| 중간 | 배경을 바꾸면 합성 결과가 자동으로 갱신되지만 어떤 지면이 다시 합성됐는지 보이지 않는다 | 완료 후 "6개 지면 다시 합성됨" 요약과 썸네일 갱신 애니메이션 |
| 낮음 | 캡션("1440×1800px · 세로형 · 기본 여백 · 로고 좌하단 · 배경 1024×1536 · 실사 제품·공간")이 길다 | 경고가 있을 때만 배지, 나머지는 툴팁 |

## 5. 편집 화면

| 우선 | 문제 | 보완 제안 |
|---|---|---|
| 높음 | 편집 화면을 **열기만 해도** 편집 요소가 만들어져, 이후 시안 화면의 "문구 다시 합성"이 409("편집한 내용이 있습니다")로 막힌다. 사용자는 아무것도 안 바꿨다고 느낀다 | 요소는 저장 시점에만 만들거나, 변경 없는 요소면 자동 합성을 막지 않기. 409 안내에 "처음 상태로 되돌리기" 버튼 직접 제공 |
| 높음 | 미리보기가 왼쪽 위에 고정돼 있지 않아 아래 제목·로고 수치를 만질 때 결과가 안 보인다 | 미리보기를 sticky 로, 컨트롤 패널만 스크롤 |
| 중간 | 위치를 숫자와 화살표로만 옮긴다(드래그 없음). 10px 단위 이동으로 큰 캔버스(2560px)에서 멀리 옮기기 힘들다 | 미리보기 위 드래그, 화살표는 Shift 로 50px |
| 중간 | 분리 자산형(PMax)은 편집 대상이 아니라 탭에 안 보이는데, 배경 자르기(초점·확대)는 그 지면에도 필요하다 | 분리 자산형도 배경만 편집 가능하게 |
| 낮음 | "닫기"와 "← 시안으로"가 같은 동작으로 두 번 있다 | 하나로 |
| 낮음 | 저장 후 다음 행동(검수)이 안내되지 않는다 | 저장 완료 메시지에 "검수하러 가기" |

## 9. 먼저 손볼 순서 제안

1. ~~이미지 썸네일 그리드(④·편집·검수 공통)~~ — **10/19 구현**(`ImageGrid`, 축소본 API). 매체 비교·배경 통일 확인이 한눈에 되고, 세 화면의 구성이 같아졌다.
