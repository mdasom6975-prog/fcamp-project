# 00. 프로젝트 정의서 (Day 1 산출물)

> 워크북 Day 1 "RFP 분석과 범위 확정" 산출물. 근거: RFP(제로피/노코더스) · RFP 개요 브리핑 · 콘텐츠 프로젝트 워크북(10/12~10/29).
> 작성일 2026-10-15 (Day 4에 소급 작성). 한 줄 정의: **이 서비스는 광고 운영 도구가 아니라 "브랜드 규칙을 지키는 광고 소재 제작·검수 도구"다.**

## 1. 목표
브랜드 규칙(로고·색상·폰트·아이콘 스타일·어조·필수/금지 표현)을 한 번 등록하면, 사용자가 고른 매체·지면 규격에 맞는 아이콘 세트·광고 이미지·카피를 생성하고, 요소별로 편집한 뒤, **브랜드·규격 검수를 통과한 파일만** ZIP으로 내려받을 수 있는 반응형 웹앱(PJ1 MVP)을 만든다.

- 생성보다 **검수가 먼저**: 규격·브랜드 규칙을 검사 가능한 데이터로 만들고, 검수 기능을 앱에 먼저 붙인다.
- 수치는 AI가 추측하지 않는다. 규격 값은 공식 문서 URL·확인일과 함께 저장하고, 미확인은 '확인 필요'로 두어 검수 통과로 표시하지 않는다.
- 시안은 이미지 한 장이 아니라 **요소(레이어)의 목록**으로 저장해 잠금·부분 수정·검수가 가능하게 한다.

## 2. 사용자
| 사용자 | 필요 |
|---|---|
| 브랜드 운영자·소상공인 | 브랜드 기준을 한 번 등록하고 아이콘·홍보 콘텐츠를 일관되게 만들고 싶다 |
| 마케팅 담당자 | 매체·지면을 고르면 바로 올릴 수 있는 규격의 소재와 카피가 필요하다 |
| 디자이너·콘텐츠 제작자 | 반복 리사이즈는 줄이되 로고·폰트·배치는 직접 통제하고 싶다 |
| 대행사·다브랜드 조직 (PJ2) | 고객사별 브랜드 분리, 시안의 매체별 버전 관리 |

적용 분야: 커머스·생활 서비스·스타트업 등 일반 브랜드 홍보. 검수 기준 브랜드: **쿠챠**(기업 제공 가이드), 교차 테스트 브랜드: **말끔**(RFP 예시 가상 브랜드).

## 3. P0 필수 범위 — 우리 말로 한 줄씩
| # | P0 기능 | 우리 말로 | 현재 구현 위치 |
|---|---|---|---|
| 1 | 브랜드 아이덴티티 등록·적용 | 브랜드 규칙 9항목을 필수/권장/수정가능 등급과 함께 저장하고, 수정하면 새 버전을 만들어 이전 버전과 시안을 보존한다 | `routers_brands.py`, `BrandPage.tsx` |
| 2 | 매체 규격 라이브러리·선택 | 플랫폼 > 광고 유형 > 지면 > 규격 버전 순서로 고르고, 조건마다 강제/권장/미표기와 출처·확인일을 보여 준다. 미확인 규격은 선택은 되지만 검수는 못 한다 | `seed.py`, `routers_presets.py`, `PresetLibrary.tsx` |
| 3 | 브랜드 기반 콘텐츠 생성 | 카피는 LLM, 배경은 이미지 모델, 로고는 원본 파일, 문구는 텍스트 레이어로 **분리 합성**한다. 아이콘은 같은 토큰으로 10개 이상 SVG | `copywriter.py`, `imagegen.py`, `compose.py`, `icons.py` |
| 4 | 기본 편집 | 요소별 문구·위치·크기·색을 바꾸고, 로고 등 핵심 자산을 잠그고, 잠긴 요소를 보존한 채 배경·문구만 재생성한다. 공통 수정과 지면별 수정을 구분한다 | `routers_edit.py`, `editing.py`, `EditPanel.tsx` |
| 5 | 검수·내보내기 | 실제로 내보낼 파일 기준으로 통과/경고/수정 필요/확인 필요를 항목별로 보여 주고, 차단 항목이 남으면 '검수 완료' ZIP을 막는다. ZIP에는 지면별 파일·copy.csv·검수결과·manifest.json | `review.py`, `routers_review.py`, `routers_export.py`, `ReviewPanel.tsx` |

P1(권장)은 P0 5개가 끝까지 이어진 뒤에만 손댄다: 다중 지면 일괄 변환(6-3에서 지면별 생성으로 일부 구현), 이력·복원·비교(스냅샷만 저장, UI 없음), 템플릿, 가이드 문서 규칙 추출.

## 4. 제외 범위 (RFP)
- 광고 계정 연결, 광고 등록·게시·예약·집행, 예산/입찰, 성과 수집·분석 — 업로드는 사용자가 직접 한다
- 영상·3D·애니메이션·HTML5 광고, 전문 디자인 도구 전체 기능, 모바일 네이티브 앱, 자체 기반 모델 학습
- 모든 플랫폼의 모든 지면 지원, 광고 심사 통과 보장
